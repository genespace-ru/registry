Welcome

Resource Registry — a component for indexing and browsing bioinformatics workflows stored in Git repositories.

The registry scans GitHub repositories for .dockstore.yml descriptor files (following the Dockstore standard) and builds an indexed catalog of workflows, tools, and notebooks with their versions, authors, and Docker images.

Key features:

  • Repository management — add and track Git repositories containing bioinformatics workflows
  • Workflow browsing — view workflows as structured lists and dependency graphs
  • Version tracking — access different versions of workflows with commit-level detail
  • Source code viewing — browse workflow scripts and descriptor files directly in the browser
